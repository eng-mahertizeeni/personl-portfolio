# Portfolio

Personal portfolio site, built with Next.js and Tailwind CSS.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- [lucide-react](https://lucide.dev) for icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All personal content (bio, skills, projects) lives in [`src/data/content.ts`](src/data/content.ts) — edit that file to update the site.

## Deployment

Deployed on [Vercel](https://vercel.com).
